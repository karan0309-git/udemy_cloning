# Udemy Clone – HTML & CSS

A basic **Udemy Clone** created using **HTML and CSS** as a frontend practice project.

## 🚀 Project Overview

This project recreates the basic layout and design of an online learning platform similar to Udemy.

The main focus is on practicing:

- HTML structure
- CSS styling
- Flexbox
- Responsive layout
- Navigation bar
- Course cards
- Pricing sections
- Buttons and basic UI components

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
Udemy-Clone/
│
├── index.html
├── style.css
└── images/
```

## ✨ Features

- Navigation bar
- Course categories
- Course cards
- Course details
- Pricing section
- Responsive design
- Basic hover effects

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

No additional installation or dependencies are required.

This project is created for **learning and practice purposes** using only HTML and CSS.
